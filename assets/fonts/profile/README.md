# Profile typography

Self-hosted, unmodified Latin WOFF2 subsets from the Google Fonts CSS API. Both
families use the SIL Open Font License 1.1; their license texts are included here.

- **Newsreader** by Production Type: headings, name, and italic personal notes.
  Upstream: https://github.com/productiontype/Newsreader
  Google Fonts webfont revision: v26. Normal variable weight 200–800, optical
  size 6–72; italic weight 400, optical size 6–72.
- **Source Sans 3** by Adobe: body copy, navigation, and academic details.
  Upstream: https://github.com/adobe-fonts/source-sans
  Google Fonts webfont revision: v20. Normal and italic variable weight 200–900.

The regular faces are preloaded. Italics load only when used. Fonts are served
from this website, so visitors do not need access to Google's font servers.
